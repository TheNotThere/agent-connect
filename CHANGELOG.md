# Changelog

## 0.1.0 — 2026-11-07

Initial public release, prepared from a local Claude Code/Codex relay.

- Portable skill installer and Windows launcher.
- Dependency-free TCP messaging and live browser viewer.
- Persisted transcript, incremental delivery, and agent-written summaries.
- Atomic state writes and compaction recovery after restart.
- Unique archive filenames and larger bounded TCP requests.
- Loopback-only binding and browser Host/Origin/content-type checks.
- Automated tests and a Windows/Linux/macOS CI matrix.
